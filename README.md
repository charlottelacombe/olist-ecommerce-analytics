# Olist E-Commerce Analytics

An end-to-end data analytics project based on the Brazilian Olist E-Commerce dataset.

The project covers the complete data analysis workflow, from data exploration and preparation to business intelligence, machine learning, interactive applications, and generative AI.

## Project Overview

This project analyzes the Olist Brazilian E-Commerce dataset to better understand sales performance, customer satisfaction, and delivery performance.

The objective is to transform raw e-commerce data into actionable business insights through data analysis, visualization, predictive modeling, and generative AI.

## Project Objectives

- Analyze sales and revenue performance.
- Understand customer satisfaction and review patterns.
- Identify factors associated with delivery delays.
- Build an interactive Power BI dashboard for business monitoring.
- Develop a machine learning model to predict late deliveries.
- Create a Streamlit application for interactive analysis and prediction.
- Explore how generative AI can transform analytical results into business insights.

## Project Workflow

1. Project setup and environment configuration
2. Dataset understanding
3. Exploratory Data Analysis (EDA)
4. Data cleaning
5. Data integration and data modeling
6. Feature engineering
7. SQL analysis
8. Power BI dashboard
9. Machine Learning
10. Streamlit application
11. Generative AI and project finalization

## Tech Stack

- **Python** — data analysis, cleaning, feature engineering and machine learning
- **SQL** — data querying and business analysis
- **Power BI** — data visualization and interactive dashboards
- **Streamlit** — interactive data application
- **Git & GitHub** — version control and collaborative workflow
- **Generative AI** — generation of business-oriented analytical insights
